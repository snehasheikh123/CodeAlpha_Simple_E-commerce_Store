# CodeAlpha_Simple_E-commerce_Store
# 🚀 E-Commerce Store – A Full-Stack Project from My CodeAlpha Internship 🌟

I'm incredibly excited to share my **fully functional E-Commerce Store** 🛍️, built from scratch during my internship at **CodeAlpha**. This project showcases my journey into full-stack web development using **HTML, CSS, JavaScript, PHP, and MySQL** — bringing real-world features like user login, product listing, shopping cart, and order processing to life!

---

## 💡 Key Features

### 🛍️ **Dynamic Product Listings**
- All products are stored in a **MySQL** database and fetched dynamically.
- Each product includes a photo, description, and price.
- Mobile-first, responsive design ensures a seamless browsing experience on all devices.

### 🛒 **Shopping Cart Functionality**
- Users can add items to the cart, update quantities, or remove products.
- Cart information is stored in **PHP sessions** — mimicking a real-world shopping experience!

### 🔐 **Secure User Authentication**
- Registration, login, and logout features implemented.
- User passwords are stored securely using hashing techniques.
- Logged-in users can place orders and view their purchase history.

### 🧾 **Order Placement with Cash on Delivery**
- Orders are stored in the backend database once checkout is complete.
- Currently supports **Cash on Delivery (COD)** to simplify transactions.
- Order tracking is integrated with the user dashboard.

### 🎨 **User-Friendly Interface**
- Clean and modern UI using **HTML & CSS**.
- Fully responsive layout for desktops, tablets, and mobile phones.
- Smooth user flow from browsing to checkout.
